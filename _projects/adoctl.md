`adoctl` is a command-line tool for taking agent-generated decompositions, validating them against team policy and Azure DevOps metadata, and bulk-creating work items with guardrails.

The project focuses on reliable automation around planning workflows: schema validation, policy checks, generated metadata, and a clear operator interface for syncing work into Azure DevOps.
